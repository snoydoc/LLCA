**Fixed Solution**:

```python
    if len(lst) == 0:
        raise ValueError("List is empty")
    return sum(lst) / len(lst)
```

2. **Raise meaningful error**: If the list is empty, we raise a `ValueError` with a clear message to indicate the issue instead of crashing with a `ZeroDivisionError`.
