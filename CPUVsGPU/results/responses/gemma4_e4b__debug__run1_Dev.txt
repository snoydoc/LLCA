The bug is that the function attempts to divide by `len(lst)` without checking if the list is empty. When `lst` is empty, `len(lst)` is 0, causing a `ZeroDivisionError`.

To fix this, you must add a check at the beginning of the function to see if the list is empty. If it is empty, you should return a value that indicates the average could not be calculated (such as `None` or 0, depending on desired behavior; returning `None` is generally clearer).

## Fixed Version

```python
def average(lst):
    """
    Calculates the average of a list of numbers.
    Returns None if the list is empty.
    """
    if not lst:  # Checks if the list is empty (len(lst) == 0)
        return None
    else:
        return sum(lst) / len(lst)

# Example Usage:
print(f"Average of [1, 2, 3]: {average([1, 2, 3])}")
print(f"Average of []: {average([])}")
```

### Alternative (Raising an Exception)

If the function is expected to *always* operate on valid data and an empty list is considered an invalid input, you might prefer to raise a `ValueError` instead of returning `None`:

```python
def average(lst):
    """
    Calculates the average of a list of numbers.
    Raises ValueError if the list is empty.
    """
    if not lst:
        raise ValueError("Cannot calculate the average of an empty list.")
    else:
        return sum(lst) / len(lst)
```
