To solve this problem, we need to create a Python function that calculates the number of days between two given dates in the format "YYYY-MM-DD". The solution involves parsing the date strings into datetime objects, computing the absolute difference between them, and returning the number of days as an integer.

### Approach
1. **Import the datetime module**: This module provides classes for manipulating dates and times.
2. **Parse the input strings**: Convert the input date strings into datetime.date objects using the `strptime` method with the format "%Y-%m-%d".
3. **Calculate the absolute difference**: Compute the difference between the two dates and take the absolute value to ensure the result is non-negative.
4. **Return the number of days**: The difference between two date objects gives a timedelta object, from which the number of days can be extracted using the `days` attribute.

### Solution Code
```python
from datetime import datetime

def days_between(date1_str, date2_str):
    """
    Calculate the number of days between two dates in 'YYYY-MM-DD' format.

    Args:
        date1_str (str): A string representing the first date.
        date2_str (str): A string representing the second date.

    Returns:
        int: The absolute number of days between the two dates.

    Example:
        >>> days_between('2023-01-01', '2023-01-03')
        2
    """
    date1 = datetime.strptime(date1_str, "%Y-%m-%d").date()
    date2 = datetime.strptime(date2_str, "%Y-%m-%d").date()
    delta = abs(date1 - date2)
    return delta.days
```

### Explanation
- **Importing datetime**: The `datetime` class from the `datetime` module is used to parse the input strings into date objects.
- **Parsing Dates**: The `strptime` method converts the input strings into date objects by matching them against the format "%Y-%m-%d".
- **Calculating Difference**: The difference between two date objects results in a `timedelta` object. The `days` attribute of this object gives the exact number of days between the two dates.
- **Absolute Value**: Using `abs` ensures the result is always positive, regardless of the order of the input dates.

This approach efficiently handles the date parsing and difference calculation, providing an accurate and straightforward solution to determine the number of days between two dates.
