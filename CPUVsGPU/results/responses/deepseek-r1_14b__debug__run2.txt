The bug occurs when the input list is empty, leading to a division by zero error. The fixed version checks for an empty list and raises a ValueError.

Here is the fixed function:

```python
def average(lst):
    if not lst:
        raise ValueError("The list is empty.")
    return sum(lst) / len(lst)
```
