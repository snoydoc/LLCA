To solve this problem, we need to create a Python function that calculates the number of days between two given dates in the format 'YYYY-MM-DD'. The solution involves converting these date strings into datetime objects, computing the difference, and returning the absolute value of that difference in days.

### Approach
1. **Parse Date Strings**: Convert the input date strings into `datetime.date` objects using Python's `strptime` method.
2. **Compute Difference**: Subtract the two datetime objects to get a timedelta object, which provides the difference between the dates.
3. **Return Absolute Value**: The days attribute of the timedelta gives the number of days between the dates. Using the absolute value ensures the result is non-negative regardless of the order of input dates.

### Solution Code
```python
from datetime import datetime

def days_between(date1, date2):
    """
    Calculate the number of days between two dates.
    
    Parameters:
        date1 (str): Date string in YYYY-MM-DD format.
        date2 (str): Date string in YYYY-MM-DD format.
        
    Returns:
        int: The absolute difference in days between the two dates.
    
    Example:
        >>> from datetime import datetime
        >>> print(days_between("2023-01-01", "2023-01-02"))
        1
    """
    def parse_date(date_str):
        return datetime.strptime(date_str, "%Y-%m-%d").date()
    
    d1 = parse_date(date1)
    d2 = parse_date(date2)
    delta = abs(d1 - d2)
    return delta.days

```

### Explanation
1. **Parsing Dates**: The `parse_date` helper function converts date strings into `datetime.date` objects using the format string `"%Y-%m-%d"`.
2. **Calculating Difference**: By subtracting one date from another, we obtain a `timedelta` object which has a `days` attribute representing the difference.
3. **Absolute Value**: Using `abs()` ensures the result is always positive, handling cases where the second date might be earlier than the first.

This approach efficiently leverages Python's datetime module to handle date manipulations accurately and concisely.
