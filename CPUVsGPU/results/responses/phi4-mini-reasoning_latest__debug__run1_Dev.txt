The bug in the `average` function occurs when an empty list is passed, causing a division by zero error. To fix this, we add a check at the beginning of the function to handle empty lists gracefully.

**Fixed Code:**
```python
def average(lst):
    if not lst:
        return 0  # Handle empty list case to avoid ZeroDivisionError
    return sum(lst) / len(lst)
```

**Explanation:**  
- **Bug Identification:** The original code attempts to divide by `len(lst)` when the list is empty, leading to a `ZeroDivisionError`.
- **Fix:** Check if the list is empty (`if not lst`). If it is, return 0 (or another appropriate value) to prevent division by zero. For non-empty lists, compute the average as before. This ensures the function handles all cases without crashing.
