The bug occurs when the list is empty because dividing by zero causes a ZeroDivisionError. The fixed function checks if the list is empty and raises a ValueError if it is.

Here is the fixed function:

```python
def average(lst):
    if not lst:
        raise ValueError("The list is empty")
    return sum(lst) / len(lst)
```
