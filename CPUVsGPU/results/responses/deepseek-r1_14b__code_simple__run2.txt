To solve this problem, we need to write a Python function that calculates the number of days between two given date strings in the format YYYY-MM-DD. This function will utilize Python's `datetime` module to handle date parsing and calculations efficiently.

### Approach
The approach to solve this problem involves the following steps:

1. **Parse Date Strings**: Convert the input date strings into `datetime.date` objects using the `strptime` method. This method allows us to specify the format of the input string, which in this case is "%Y-%m-%d".
2. **Calculate Date Difference**: Subtract the two date objects to get a `timedelta` object, which represents the duration between the two dates.
3. **Extract Days**: The `timedelta` object has an attribute `days` that gives the number of days between the two dates. We take the absolute value of this difference to ensure the result is non-negative, regardless of the order of the input dates.

### Solution Code

```python
import datetime

def days_between(date1, date2):
    """
    Calculate the number of days between two dates.
    
    Parameters:
        date1 (str): First date string in YYYY-MM-DD format.
        date2 (str): Second date string in YYYY-MM-DD format.
        
    Returns:
        int: The absolute number of days between the two dates.
        
    Example:
        >>> days_between('2020-01-01', '2020-01-10')
        9
    """
    # Convert both date strings to date objects
    date_obj1 = datetime.datetime.strptime(date1, "%Y-%m-%d").date()
    date_obj2 = datetime.datetime.strptime(date2, "%Y-%m-%d").date()
    
    # Calculate the difference
    delta = date_obj2 - date_obj1
    
    # Return the absolute number of days
    return abs(delta.days)
```

### Explanation
- **Parsing Dates**: The `strptime` method is used to convert each date string into a `datetime.date` object. This method is chosen because it efficiently handles the specified date format.
- **Calculating Difference**: By subtracting the two date objects, we obtain a `timedelta` object. The `days` attribute of this object gives the number of days between the two dates.
- **Absolute Value**: Using the absolute value ensures that the function returns a non-negative number of days, regardless of which date comes first.

This approach ensures that the function is both efficient and easy to understand, leveraging Python's built-in capabilities for date handling.
