```python
from pathlib import Path

class FileManager:
    """A class representing a file manager with operations on files and directories."""
    
    def __init__(self, base):
        """
        Initialize the FileManager with a base directory.
        
        Args:
            base (str): The path to the base directory. Must be an existing directory.
            
        Raises:
            ValueError: If the provided base is not a valid directory.
        """
        self.base = Path(base)
        if not self.base.is_dir():
            raise ValueError(f"{base} is not a valid directory")
    
    def read_file(self, filename):
        """Read the contents of the specified file relative to the base directory.
        
        Args:
            filename (str): The name of the file to be read.
            
        Returns:
            str: The content of the file.
            
        Raises:
            FileNotFoundError: If the file does not exist in the base directory.
        """
        path = self.base / filename
        if not path.exists():
            raise FileNotFoundError(f"File {path} does not exist.")
        return path.read_text()
    
    def write_file(self, filename, data):
        """Write data to the specified file relative to the base directory.
        
        Args:
            filename (str): The name of the file to be written.
            data (str): The data to write into the file.
            
        Returns:
            None
        
        Raises:
            RuntimeError: If an error occurs during writing, such as permission issues.
        """
        path = self.base / filename
        try:
            with path.open('w') as f:
                f.write(data)
        except Exception as e:
            raise RuntimeError(f"Failed to write {path}: {e}") from e
    
    def list_files(self):
        """List all files and directories in the base directory.
        
        Returns:
            List[str]: Names of files and directories, including hidden entries like '.' and '..'.
            
        Raises:
            ValueError: If the base path does not exist or is not a directory.
        """
        if not self.base.is_dir():
            raise ValueError(f"{self.base} is not a valid directory")
        dir_path = self.base / ''
        return [entry.name for entry in dir_path.glob('*')]
```

### Explanation
- **Initialization**: The `FileManager` class initializes with a base directory. It checks if the provided path is a valid directory and raises an error if it is not.
- **Reading Files**: The `read_file` method constructs the full path to the file, checks for its existence, and reads its content using `pathlib`.
- **Writing Files**: The `write_file` method handles exceptions during writing operations by wrapping them in a `RuntimeError`, ensuring any issues are reported with context.
- **Listing Entries**: The `list_files` method verifies the base directory is valid before listing all entries, including hidden ones, using `glob('*')`.

This approach ensures that each function adheres to snake_case naming conventions, includes comprehensive documentation, and handles edge cases as required.
