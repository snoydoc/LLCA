To solve this problem, we need to create a Python function that calculates the number of days between two given dates in the 'YYYY-MM-DD' format. The solution must be efficient and leverage Python's built-in capabilities for date manipulation.

### Approach
1. **Convert Date Strings to Date Objects**: Utilize Python's `datetime` module to parse the input date strings into `date` objects. This allows us to use arithmetic operations on dates.
2. **Calculate the Difference**: Subtract the two date objects to get a `timedelta` object, which contains information about the difference between the dates. The `.days` attribute of this object gives the number of days between the two dates.
3. **Handle Order Irrelevance**: Use the absolute value of the difference to ensure the result is non-negative regardless of the input order.

### Solution Code
```python
from datetime import date

def days_between(date1: str, date2: str) -> int:
    """
    Calculate the number of days between two dates.

    Parameters:
    date1 (str): The first date in 'YYYY-MM-DD' format.
    date2 (str): The second date in 'YYYY-MM-DD' format.

    Returns:
    int: The absolute difference in days between the two dates.

    Example:
    >>> days_between("2023-01-01", "2023-01-05")
    4
    """
    d1 = date.fromisoformat(date1)
    d2 = date.fromisoformat(date2)
    return abs(int((d2 - d1).days))

# Usage example
if __name__ == "__main__":
    print(days_between("2023-01-01", "2023-01-05"))  # Output: 4
```

### Explanation
1. **Date Conversion**: The function `date.fromisoformat` converts the input strings into `date` objects, which handle date arithmetic correctly.
2. **Difference Calculation**: Subtracting two `date` objects results in a `timedelta` object. The `.days` attribute of this object gives the number of days between the dates.
3. **Absolute Difference**: Using `abs` ensures that the result is always non-negative, regardless of which date comes first.

This approach efficiently leverages Python's built-in modules to handle complex date calculations, ensuring accuracy and simplicity in implementation.
