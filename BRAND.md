# LCCA brand identity

LCCA stands for **Local Cognitive Coding Agency**.

## Logo
- Primary logo: `assets/brand/lcca-logo.svg`
- App icon / favicon: `assets/brand/lcca-mark.svg`
- Use the logo at its original proportions. Keep clear space around the symbol.
- The symbol uses a simple folded-ribbon form to suggest connected reasoning and controlled code transformation.

## Typography
Use **Inter** where available, with Segoe UI or Arial as fallbacks. Prefer bold, clean sans-serif headings and restrained letter spacing.

## Style
Minimal, friendly, modern developer tooling. Use bright gradients as accents, generous whitespace, simple geometry, and high-contrast text. Avoid heavy glow, metallic effects, complex circuit illustrations, and visual clutter.

## Product language
Describe capabilities precisely: local execution, AST-based edits, transactional changes, validation, and rollback. Do not imply guarantees beyond the implementation.
